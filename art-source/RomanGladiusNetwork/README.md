# RomanGladius Network source art

The PNGs in this directory are the source artwork used by
`tools/make_roman_gladius_assets.py` to compile the Civ V DDS textures.

- `RomanGladiusConcept.png` — supplied concept sheet and canonical heraldry.
- `RomanGladiusLeader.png` — supplied wide leader/city scene.
- `RomanGladiusMap.png` — supplied network map scene.
- `ServerConsole.png` — standalone building illustration generated from the supplied concept sheet.

The generated building prompt is recorded in `RomanGladius-Prompts.md`.
