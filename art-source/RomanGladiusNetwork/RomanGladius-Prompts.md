# RomanGladius Network art prompt

Built-in image generation was used for one project asset. The supplied concept art remains the source for the leader, Dawn of Man, map, civilization emblem, and Server Owner portrait.

## Server Console

- Use case: stylized-concept
- Asset type: Civilization V unique-building icon source art for the Server Console
- Primary request: Create a clean standalone illustration of the Server Console from the supplied RomanGladius Network concept sheet. It must remain extremely close to the reference design: a Minecraft-inspired dark stone-and-heavy-timber open command hall, crenellated block architecture, warm hanging square lanterns, a large desk with several glowing green server-monitor panels and a central world map display, a small suspended glowing blue-green voxel globe, and deep crimson banners bearing the same simple gold castle/network heraldry. No people.
- Input images: supplied concept sheet as the primary design reference; supplied leader and map scenes as supporting palette/world references
- Scene/backdrop: isolated heroic three-quarter exterior/interior view with a subtle warm parchment-toned atmospheric background
- Style/medium: polished painterly fantasy strategy-game concept art with block-built Minecraft visual language, matching the references
- Composition/framing: centered square composition, full building visible, strong silhouette and readable console desk, suitable for circular cropping
- Lighting/mood: warm golden lantern light against dark charcoal stone; welcoming, organized, prestigious
- Color palette: charcoal, dark oak, crimson, antique gold, small green and cyan screen accents
- Constraints: preserve the reference building's architecture, banner design, command-desk arrangement, suspended globe, and warm lighting; no readable text; no logos beyond the simple gold castle/network heraldry; no watermark; no border; no UI frame
- Avoid: modern photoreal office, sci-fi spaceship, generic medieval castle, excessive visual clutter, characters, cropped building
