# Paradise original art

Generated with the built-in imagegen tool. Direct public-figure portrait generation was rejected; the specification explicitly permits a fictional Argentine Number Ten fallback. These are original illustrations, not photographs or broadcaster material. The four selected source paintings are committed here; finished DDS are committed under `TheBoyWhoTouchedParadise/Art`.

`tools/make_paradise_assets.py` compiles the paintings, original vector-style civic/object emblems, an Argentine loading map, circular icons, alpha/flag atlases and the coherent Journey panels. DirectXTex produces legacy BC3 or RGBA DDS and full mip chains. All 39 textures ship; users never need to run the generator to install. `ParadiseArtPreview.png` shows the selected paintings and game icons.
