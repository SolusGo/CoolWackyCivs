# The RomanGladius Network

**Leader:** Lachlan “RomanGladius”
**Civilization:** The RomanGladius Network
**Capital:** Main Server
**Preferred Victory:** Science / Culture / Diplomatic
**Playstyle:** Tall, population-focused, economic, management-heavy
**Theme:** Managing a successful Minecraft server network, where Cities are Servers and Population represents Players.

## Unique Ability — The Server Network

**Every City is treated as a Server, and every point of Population represents one Player connected to that Server.**

Each Server has its own:

* **Player Roster**
* **Moderators**
* **Administrator**
* **Server Reputation**
* **Chat Log**
* **Random Server Events**

Population provides additional bonuses representing community activity:

**Every 2 Players:** +1 Gold
**Every 4 Players:** +1 Science
**Every 5 Players:** +1 Culture

Larger Servers therefore become extremely productive, but also generate more management problems.

Each Server possesses **0–100 Server Reputation**.

Higher Reputation increases Growth, Gold, and the chance of positive events. Low Reputation reduces Growth and may cause Players to leave the Server.

### Server Reputation

**90–100 — Legendary**

* +20% Growth
* +15% Gold
* +10% Culture
* Positive events greatly increased

**70–89 — Thriving**

* +10% Growth
* +10% Gold
* Positive events increased

**50–69 — Stable**

* No modifier

**30–49 — Troubled**

* -10% Growth
* Negative events increased

**10–29 — Toxic**

* -20% Growth
* -10% Gold
* Players may leave

**0–9 — Dead Server**

* Severe chance of Population loss
* Very poor Growth

Players can be promoted into staff positions.

Every Population point begins as a normal Player.

Players provide the normal Population benefits alongside bonuses from the Unique Ability.

Players may also possess hidden personality traits that influence Server Events.

Possible Player types include:

* Builder
* PvPer
* Redstoner
* Veteran
* Troll
* Donator
* Potential Staff
* Cheater

---

## Moderator

Available once a Server reaches **4 Population**.

A Player may be promoted into a Moderator by spending Gold.

Moderators:

* Reduce the chance of cheating
* Reduce griefing
* Reduce toxic-chat events
* Improve Server Reputation recovery
* Generate +1 Culture
* May automatically resolve minor Server Events

However, too many Moderators increase the chance of:

* Moderator Abuse
* Staff Arguments
* Unfair Bans
* Favouritism
* Power Struggles

An ideal Server maintains approximately **1 Moderator for every 4–6 Players**.

Servers with too few staff become **Undermoderated**.

Servers with excessive staff become **Overmoderated**.

---

## Administrator

Available in Servers with at least **8 Population**.

One Moderator may be promoted into an Administrator.

Normally limited to **1 Administrator per Server**.

Administrators:

* Greatly reduce severe negative events
* Improve Reputation recovery
* Increase Moderator effectiveness
* May automatically resolve major incidents

Administrators cost:

**2 Gold per turn**

Poor Administrators can also trigger severe staff-related events.

# Unique Unit — Server Owner

**Replaces:** Settler

The Server Owner represents Lachlan creating and launching another Minecraft server.

Unlike a normal Settler, creating additional Servers is deliberately expensive.

### Server Owner

**Production Cost:** 160% of normal Settler cost

Training a Server Owner consumes:

**2 Population instead of 1**

Launching a Server additionally costs Gold based on the number of Servers already controlled.

Example:

**Second Server:** 100 Gold
**Third Server:** 200 Gold
**Fourth Server:** 300 Gold
**Fifth Server:** 400 Gold

When a Server Owner founds a City:

* Receives a free **Server Console**
* Begins with **60 Server Reputation**
* Receives **Grand Opening** for 10 turns

### Grand Opening

**+50% Growth for 10 turns**

Represents the influx of Players after the launch of a new Server.

The Server Owner therefore makes expansion expensive, encouraging the RomanGladius Network to maintain a small number of highly populated Servers.

Each Server periodically generates flavour Chat messages.

Most messages have no gameplay effect.

Example:

> [Steve2004] anyone got diamonds
> [EnderSteve] nah
> [Steve2004] roman
> [Steve2004] roman
> [RomanGladius] what

Other messages may precede actual gameplay Events.

Example:

> [DiamondMiner] OWNER
> [DiamondMiner] THIS GUY IS FLYING
> [CraftKing42 MOD] yeah he's hacking

This may trigger:

### Suspected Cheater

A Player has been accused of cheating.

Possible responses:

**Ban Player**

* Lose 1 Population
* +8 Reputation

**Investigate**

* Chance to discover whether the Player was actually cheating

**Ignore**

* No immediate penalty
* Severe Reputation loss if cheating is later confirmed

# Random Server Events

The RomanGladius Network periodically experiences events based on:

* Population
* Reputation
* Number of Moderators
* Administrator presence
* Player personalities
* Current Server Activity

Possible negative events include:

### Griefer Attack

Player builds have been destroyed.

Possible solutions include:

* Roll back the Server
* Allow Moderators to handle it
* Ignore the damage

---

### Moderator Abuse

Possible responses:

* Demote Moderator
* Defend Staff Member
* Investigate Incident

---

### Staff Civil War

Two Moderators begin arguing and disrupting the Server.

Possible responses:

* Demote Moderator A
* Demote Moderator B

* Allow them to resolve it themselves

---

### Server Crash

Possible responses:

* Restart immediately
* Debug the problem
* Roll back the Server

* Temporary Gold and Production

# Server Activity

Every Server possesses an Activity state.

### Active

High Reputation and recent successful events.

* Increased Growth
* More positive Server Events

### Quiet

Normal state.

No major bonuses or penalties.

### Inactive

Low Reputation or poor recent activity.

* Reduced Growth
* Players may leave

Population loss is presented as Players leaving the Server.

Example:

> ***Steve2004 left the server.***

Large Reputation collapses may cause several Players to leave simultaneously.

# Strategy

The RomanGladius Network is designed around **building a small number of enormous, successful Cities rather than rapidly expanding**.

Launching additional Servers is expensive, and every new Server creates another community that must be moderated.

The Network becomes increasingly powerful as its Servers grow.

Large populations generate substantial:

**Gold, Science and Culture**

but also dramatically increase the frequency of:

**Cheaters, Griefers, Staff Drama, Server Crashes and Community Events.**

The ideal RomanGladius player should therefore focus on:

**Growth → Reputation → Moderation → Community → Revenue**

A well-managed 25-Population Server can become enormously productive.

A poorly managed 25-Population Server can completely collapse.

# Design Identity

**Core Gameplay Loop:**

**Launch Server → Attract Players → Appoint Staff → Build Reputation → Handle Community Events → Grow Server → Generate Revenue → Expand Network**

The RomanGladius Network is effectively a **Minecraft server-management simulator layered on top of Civilization V**, with every City representing an independent multiplayer Server and every Population point representing an actual Player in the community.
