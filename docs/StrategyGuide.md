## Reading an advantage

An opportunity names a condition you can exploit. A threat names a timing, resource or position to respect. Neither is an automatic counter or a tested ranking. Start with food, sustainable expansion, defense and a viable treasury; a signature mechanic does not exempt its owner from those costs.

For each civ, read Opening priorities, Develop the engine and Convert the advantage in order. Pros and cons explain the tradeoffs; Common mistakes covers the most likely misread rules. Exact values and engine limits remain in the linked full mechanics guides.

## In-game reference

Open Civilopedia and select the civilization or its leader. Practical strategy appears first, followed by the existing lore/biography. Each collection uses unique article keys, preserving independent guide text when both are loaded. English is supplied; other translations are not claimed.

## Maintaining the guides

Edit `docs/StrategyGuides.json`, then run `python tools/generate_strategy_guides.py`. `python tools/validate_strategy_guides.py` checks generated files, complete article chapters, preserved lore and gameplay data. Rebuild the package after regeneration.
