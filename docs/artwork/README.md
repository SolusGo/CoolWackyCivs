# Repository artwork

[Collection README](../../README.md) · [Civilization gallery](../Civilizations.md)

The cover was created for this repository using built-in ImageGen. Each JPEG in `leaders/` is a web preview of the matching civilization's diplomacy scene. The original texture is the `FallbackImage` named in that civilization's `Art/*LeaderScene.xml`.

## Cover prompt

```text
Use case: stylized-concept. Asset type: wide GitHub README cover illustration for the first Cool Wacky Civs mod pack. Paint one coherent panorama using the pack's themes: a walled medieval city on an island of cliffs, a few copper-and-teal astronomical instruments on the foreground rampart, and a luminous futuristic observatory emerging among foothills against a warm sunrise. Tiny original silhouettes for scale. A richly rendered strategy-game concept painting with clear composition, amber morning light, teal shadows and slate cliffs. Compose as an ultra-wide landscape banner (ideally 3:1) with all the important scenery in the central horizontal third so it can be cropped wide. The city and its mountain silhouette should read clearly at small size. No title, typography, glyphs, interface, frame, logos, or watermark.
```
